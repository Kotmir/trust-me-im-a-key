Генератор API-ключей

Случайный секретный ключ для вашего сервиса. Создаётся прямо в браузере.

Ваш ключ

Не удалось скопировать автоматически. Нажмите на ключ, чтобы выделить его целиком, и скопируйте через Ctrl+C.

Формат

Необязательно. Допустимы латиница, цифры, «_» и «-».

Ключи создаются через Web Crypto API. Страница не отправляет данные по сети и не сохраняет сам ключ, поэтому после закрытия вкладки он пропадёт. Сохраните его в менеджере паролей или в файле .env.
