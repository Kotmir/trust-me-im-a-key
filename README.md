# Генератор API-ключей

Одна страница, которая создаёт случайный секретный ключ и копирует его в буфер обмена.
Работает без сборки и без интернета: ключ создаётся прямо в браузере.

## Как открыть

Дважды щёлкните по `index.html`. Больше ничего устанавливать не нужно.

Чтобы выложить на сайт, загрузите папку целиком на любой статический хостинг.

## Что умеет

- **Четыре формата:** UUID v4, Hex, Base62, Base64url.
- **Длина** от 16 до 128 символов (для UUID всегда 36).
- **Префикс** до 16 символов, например `ktm_live_`. Допустимы латиница, цифры, `_` и `-`.
- **Копирование в один клик.** Работает и когда страница открыта с диска.
- **Оценка надёжности** в битах энтропии и в четыре уровня.
- **Скрытие ключа**, чтобы не показывать его на демонстрации экрана.
- **Светлая и тёмная тема.** По умолчанию берётся из системы, выбор запоминается.
- **Цветовая подсветка:** префикс зелёный, цифры латунные, буквы тёмные. Ключ проще читать и диктовать.

Горячие клавиши (когда фокус не в поле ввода): **G** создаёт новый ключ, **C** копирует текущий.
Они работают в любой раскладке.

## Структура

```
api-key-generator/
├── index.html
├── README.md
└── assets/
    ├── css/style.css    стили и цветовые токены
    └── js/
        ├── keygen.js    ядро: генерация и оценка надёжности
        └── app.js       интерфейс
```

## Что можно настроить

| Что                       | Где                                            |
|---------------------------|------------------------------------------------|
| Цвета и шрифты            | блок `:root` в начале `assets/css/style.css`   |
| Формат и длина по умолчанию | `DEFAULTS` в начале `assets/js/app.js`       |
| Диапазон длины            | `MIN_LENGTH` и `MAX_LENGTH` в `assets/js/keygen.js` |
| Новый формат ключа        | добавьте запись в `FORMATS` в `keygen.js`, радиокнопку в `index.html` и подсказку в `FORMAT_HINTS` в `app.js` |

## Что изменилось по сравнению с исходной версией

- **Безопасная генерация.** Раньше ключ строился через `Math.random()`, он предсказуем и не годится для секретов.
  Теперь используется `crypto.getRandomValues` с отбраковкой байтов, чтобы символы выпадали равномерно.
- **Без jQuery.** Скрипты написаны на чистом JavaScript, страница не зависит от внешних библиотек.
- **Исправлен CSS.** В исходном файле стили были продублированы, а первое правило оборвано без закрывающей скобки.
  Стили переписаны с нуля.
- **Полноценная страница.** Исходный HTML был фрагментом без `<head>`, подключения стилей и скриптов.

## Безопасность

- Страница не делает сетевых запросов и не подключает внешние шрифты и скрипты.
- Сам ключ нигде не сохраняется. В `localStorage` попадают только настройки (формат, длина, префикс) и тема.
- Ключ, созданный в браузере, подходит для ручного получения секретов: переменных окружения, подписей вебхуков, служебных токенов.
  Ключи, которые вы выдаёте пользователям своего сервиса, нужно создавать и хранить на сервере.

## Поддержка браузеров

Актуальные Chrome, Edge, Firefox и Safari. В старых браузерах без поддержки `cqw`
ключ показывается стандартным размером шрифта и просто переносится на следующую строку.
